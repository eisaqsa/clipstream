# ClipStream — FAQ и решение проблем

Короткие ответы на частые вопросы и типичные ошибки. Если ответа нет — откройте
[Issues](https://github.com/eisaqsa/clipstream/issues) и опишите проблему.

## Установка и запуск

**Нужен ли Python или FFmpeg?**
Нет. Скачайте `ClipStream-Setup-*.exe` из [Releases](https://github.com/eisaqsa/clipstream/releases/latest),
установите и запустите ярлык ClipStream. Python, FFmpeg и модель субтитров
программа скачает сама при первом запуске.

**Нужны ли права администратора?**
Нет. Установка идёт в `%LOCALAPPDATA%\Programs\ClipStream` для текущего
пользователя, без UAC.

**Windows пишет «Неизвестный издатель». Это вирус?**
Нет. Код не подписан платным сертификатом, поэтому SmartScreen показывает
предупреждение. Нажмите **Подробнее → Выполнить всё равно**. Установщик
лежит в Releases; ClipStream распространяется бесплатно (см. [LICENSE](LICENSE)).

**Сколько скачивается при первом запуске?**
Около 570 МБ (FFmpeg 86 МБ, yt-dlp 22 МБ, модель субтитров 486 МБ) и около
690 МБ на диске. Повторные запуски ничего не качают.

**Можно ли пользоваться без интернета?**
Да. После первой загрузки компонентов интернет не нужен: клипы режутся из
локальных файлов. Без интернета на первом запуске можно нажать
**«Продолжить без субтитров»**.

## Работа программы

**Откуда можно брать видео?**
Ссылка на Twitch, YouTube, Kick, VK или локальный файл на компьютере.

**Есть ли лимиты или водяные знаки?**
Нет. Программа бесплатная, всё считается на вашем компьютере.

**Почему клип получился 60 fps, а не 30?**
Частота клипа по умолчанию равна частоте записи. Задайте нужную вручную:
`--fps 30` (или `60`, `120`).

**Почему нет субтитров?**
Скорее всего, в записи нет речи (только музыка/выстрелы). ClipStream не
выдумывает субтитры. Если модель не скачана — включите флажок субтитров,
окно предложит её загрузить.

**Где лежат готовые клипы?**
По умолчанию `%LOCALAPPDATA%\ClipStream\out`. Папку можно сменить в блоке
«04 · ЗАПУСК» → **КУДА СОХРАНИТЬ…**; путь запоминается.

**Как обновить yt-dlp, если видео перестало скачиваться?**
Шапка окна → **ЗАГРУЗКИ** → «Проверить обновление yt-dlp» (или из консоли
`bin\yt-dlp.exe -U`).

## Типичные ошибки

**`ffmpeg не найден`**
Нажмите **ЗАГРУЗКИ** в шапке окна и докачайте компоненты.

**`yt-dlp не найден`**
То же: **ЗАГРУЗКИ** → докачать, затем при необходимости обновить yt-dlp.

**«Файл повреждён (не сошлась контрольная сумма)»**
Просто повторите загрузку: битый файл удаляется и скачивается заново
автоматически (докачка с места обрыва, повторы).

**Субтитры квадратиками**
В системе нет шрифта Arial (маловероятно). Установите стандартные шрифты Windows.

**Окно мыльное при масштабе 125–150%**
Окно учитывает DPI. Если всё равно мыло — поставьте масштаб 100% для
`ClipStream.exe` (Свойства → Совместимость).

**Twitch-клип начинается не с того момента**
Используйте `--fast` — программа качает только нужный кусок. Twitch иногда
отдаёт его со сдвигом 10–20 секунд.
