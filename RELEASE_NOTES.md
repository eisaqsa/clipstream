# Релизы ClipStream

Установщики — в разделе [Releases](https://github.com/eisaqsa/clipstream/releases).
Каждый файл проверяется по SHA-256, указанному в описании релиза.

**Лицензии версий различаются.** 1.1.0 и более ранние распространялись по
MIT, права их получателей сохраняются (текст — в
[LICENSE-MIT-1.1.0.txt](LICENSE-MIT-1.1.0.txt)). Начиная с 1.1.1 действует
проприетарная лицензия [LICENSE](LICENSE) и [EULA.txt](EULA.txt).

## 1.1.1 — проприетарная лицензия

**Файл:** `ClipStream-Setup-1.1.1.exe` · 64 703 754 Б (61,7 МБ)
**SHA-256:** `5B342878BE35AFF8843512BE35ADDC56A6CBEE4814171C0BCEE9B3CA0AD27ACD`

### Что изменилось

- **Лицензия.** ClipStream остаётся полностью бесплатным: все функции, без
  подписки, без платных опций и лицензионных ключей. Код будущих версий
  закрыт. Перепродажа программы и распространение её сборок без разрешения
  правообладателя запрещены. Созданные вами клипы можно свободно публиковать
  и монетизировать.
- **EULA в установщике.** При установке показывается пользовательское
  соглашение; уведомления о сторонних компонентах — на следующем экране и в
  файле `THIRD_PARTY_LICENSES.md` рядом с программой.
- **Меньше размер.** PyAV и связанные библиотеки убраны из сборки: установщик
  стал на ~16,6 МБ меньше, распакованная программа — на ~65 МБ.
- **Исправлен Auto Blur.** Размытие больше не падает на маленьких областях
  (`Invalid chroma_param radius value`).

### Установка

1. Скачайте `ClipStream-Setup-1.1.1.exe` из Assets.
2. Запустите установщик, дождитесь ярлыка **ClipStream** на рабочем столе.
3. Первый запуск: программа скачает FFmpeg, yt-dlp и модель субтитров
   (~570 МБ) с прогрессом и проверкой SHA-256.

Windows может предупредить «Неизвестный издатель» — установщик не подписан
платным сертификатом: **Подробнее → Выполнить всё равно**.

### Проверено

Установка и запуск на Windows 11, распознавание речи, VAD, субтитры, цензура,
Auto Blur, экспорт 1080×1920. **Чистая Windows 11 без Python и VC++ отдельно
не тестировалась** — если что-то не запустится, напишите в Issues.
